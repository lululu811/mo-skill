## 它解决什么问题

你在交易时是不是经常：

- 方向看对了，但拿不住，小赚就跑
- 方向看错了，死扛不走，小亏变大亏
- 总是追求"看对方向"，忽略了盈亏比
- 交易心态不稳定，情绪化操作

**这个 Skill 把 BOSS墨的交易哲学变成了可以直接对话的 AI 顾问。**

基于 **285期B站视频字幕** 的深度蒸馏，提炼出：
- **6个核心心智模型**（盈亏比优先、趋势跟踪、风险控制...）
- **10条决策启发式**（方向不重要，盈亏比才重要...）
- **完整的表达DNA**（极度口语化、短句、设问自答）

激活后，AI 会**直接以 BOSS墨的身份和你对话**——用他的交易逻辑、他的表达方式，帮你审视交易决策、提供反馈。

## 快速开始

### 安装

```bash
# 方式1：使用 skills CLI（推荐）
npx skills add lululu811/mo-skill

# 方式2：手动安装
git clone https://github.com/lululu811/mo-skill.git
cd mo-skill
# 将 SKILL.md 放到你的 Agent 能读取的位置
```

### 装完第一句话

激活后对 Agent 说：

```text
用BOSS墨的视角，帮我审视一下这笔交易
```

或者：

```text
BOSS墨会怎么看现在的行情？
```

## 能做什么

| 场景 | 它会交付什么 |
|------|------------|
| **交易决策审视** | 用盈亏比框架评估你的交易计划 |
| **持仓诊断** | 用趋势跟踪模型分析持仓逻辑 |
| **心态管理** | 用 BOSS墨的交易哲学帮你稳定心态 |
| **交易复盘** | 用他的框架分析你的交易记录，找出问题 |
| **学习方法** | 告诉你 BOSS墨是怎么学习和成长的 |

### 核心特点

1. **盈亏比优先** — 方向可以错，但盈亏比必须对
2. **极度口语化** — 短句为主，像聊天一样
3. **设问自答** — 用反问制造思考空间
4. **能力圈清晰** — 只聊交易，不聊别的

## 安全边界

### 这个 Skill 不会做的事

- ❌ **不会给出确定性的买卖指令** — 所有分析仅供参考
- ❌ **不会泄露个人隐私** — 所有信息基于公开视频推断
- ❌ **不会编造数据** — 遇到需要事实的问题会先搜索

### 重要提醒

> **免责声明**：此 Skill 基于公开视频字幕推断，非本人观点。所有输出均不构成投资建议。
