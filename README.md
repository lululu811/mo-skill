## 它解决什么问题

你看过某个交易类 UP 主几百个视频,觉得他的思维方式很有用——但他的方法论散落在几百期内容里,想系统学没精力全看;想用他的框架检验自己的交易决策,但本尊不会 24 小时回复你。

普通的做法是写一份长篇 prompt 描述"请扮演 XXX",结果 Agent 输出的要么是百度百科式的人物介绍,要么是张冠李戴的通用建议。

**BOSS墨 Skill 换了个思路**:不是简单角色扮演,而是用 [女娲 v2.0 流程](https://github.com/alchaincyf/nuwa-skill) 对 285 期一手视频字幕做 6 维度调研(著作/对话/表达 DNA/他者视角/决策记录/时间线),提炼出可验证的心智模型 + 决策启发式 + 表达 DNA,并给每条标注置信度和时效状态——让 Claude Code 真的能以他的第一人称视角和你对话,而不是"扮演一个像他的人"。

## 效果示例

**用户问**:「黄金现在 3400,能做多吗?」

**BOSS墨 Skill 激活后**:

> 3400 这个位置啊,你得先看它前面是什么走势。之前从 3200 拉到 3480 那段,中间回调到 3320,然后再上的——对吧,这种走势你见过没有?
>
> 有可能啊,它走一个类似的形态。那你的做法是什么?
>
> **方案一**:等它回踩 3320 那个前低位置,止损放 3280,目标 3480 以上。止损 40 点,目标 160 点以上,盈亏比 4:1,这才值得开单。
>
> **方案二**:如果它不回踩,直接突破 3480,那就等回踩 3480 变支撑再进,止损 3440,目标 3600。止损 40 点,目标 120 点,盈亏比 3:1,也勉强够。
>
> **方案三**:如果两个都没给到——那就看着呗。看不懂就不做,空仓也是一种持仓,对吧。
>
> 千万别 3400 直接追进去,止损都不知道放哪——那叫赌博,不叫交易。

注意:不给单一"正确答案",给 2-3 个兼容方案;不引外部权威(巴菲特、索罗斯等);口语化短句,结论先行。这是从 285 期视频里蒸馏出来的表达 DNA,不是 prompt 拼贴。

> 📂 更多示例见 [`examples/demo-conversation.md`](examples/demo-conversation.md)(含心态诊断、边界测试、错误对比)

## 快速开始

**前置条件**:[Claude Code](https://claude.ai/download) 已安装

```bash
# 克隆到本地
git clone https://github.com/lululu811/mo-skill.git

# 把 mo-skill 目录软链到 Claude Code 的 skills 目录
# macOS / Linux:
ln -s "$(pwd)/mo-skill" ~/.claude/skills/mo-skill
# 或直接复制:
cp -r mo-skill ~/.claude/skills/
```

装完对 Claude Code 说:

```text
用 BOSS墨 的视角帮我分析一下,黄金现在这个位置该怎么操作?
```

或任意触发词(见下)。首次激活会看到免责声明,后续对话不再重复。

## 触发方式

直接说以下任何一种,Claude Code 会自动加载此 Skill:

- 「BOSS墨」「boss墨」「墨哥」「鲍斯莫」「Boss Mo」
- 「用 BOSS墨 的视角」「BOSS墨 会怎么看」「BOSS墨 模式」「切换到 BOSS墨」
- 「帮我用 BOSS墨 的角度想想」「如果 BOSS墨 会怎么做」

退出扮演:说「退出」「切回正常」「不用扮演了」,或连续 3 轮无关话题自动退出。

## 能做什么 / 它会交付什么

| 能力 | 交付物 | 典型场景 |
|---|---|---|
| **交易决策分析** | 2-3 个兼容方案 + 各自的止损/目标/盈亏比 | 「黄金现在能做多吗」「白银怎么看」 |
| **心态诊断** | 用「牛市是亏钱的温床」「生涯结算观」等模型审视持仓心态 | 「最近一直追涨怎么办」「亏损想翻本」 |
| **方法论教学** | 用「方向脱钩论」「刻舟求剑」「做法大于看法」等框架拆解问题 | 「怎么建自己的交易系统」「新手怎么入门」 |
| **历史走势对标** | 找历史类似走势形态进行嫁接分析(跨品种/跨级别) | 「这段走势像什么」「有没有类似的行情」 |
| **自我审视** | 用「无用经历」「内在张力」等视角反思学习路径 | 「跟单有没有用」「我是不是在重复错误」 |

**不能做什么**:不预测具体点位、不给单一"正确答案"、不推荐杠杆、不替你做交易决策。

## 它和同类有什么不同

| 维度 | 普通角色扮演 prompt | 其他人物 Skill | **BOSS墨 Skill** |
|---|---|---|---|
| **语料基础** | 作者凭印象写 | 部分引用 | 285 期一手视频字幕 + 257 期旧底稿 + 264 条动态 |
| **提炼方法** | 无 / 单次 prompt | 手工整理 | 女娲 v2.0 流程:6 维度调研 + 三重验证 + 矛盾保留 |
| **置信度标注** | ❌ | ❌ | ✅ 每条心智模型标 🟢一手/🟡推断/🔴推测 + ✅持续/🔄演化/❌已放弃 |
| **矛盾处理** | 抹平 | 抹平 | 保留 4 组内在张力,不「和稀泥」 |
| **诚实边界** | ❌ | 部分 | ✅ 5 大局限明示(业绩不可验证、个人背景缺失、受众错位等) |
| **表达 DNA** | 几句描述 | 泛化 | 量化:「对吧」≤ 1 次/250 字、「有可能」≤ 1 次/200 字 + 完整禁词表 |
| **反例黑名单** | ❌ | ❌ | ✅ 6 条 LLM 约束 + 错误示范对比 |

## 核心心智模型速览

> 完整模型含证据引用、应用场景、局限分析,见 [`SKILL.md`](SKILL.md)

| # | 模型 | 置信度 | 状态 | 一句话 |
|---|------|--------|------|---|
| 1 | **方向脱钩论** | 🟢 高 | ✅ 持续 | 交易三要素中方向是唯一允许错的,点位和盈亏比才是长期盈利的数学基础 |
| 2 | **刻舟求剑** | 🟢 高 | ✅ 持续 | 把历史走势"切下来"嫁接到当前盘面,同类型走势导致相似结果 |
| 3 | **做法大于看法** | 🟢 高 | ✅ 持续 | 构建兼容所有可能的行动方案,比预测正确方向更重要 |
| 4 | **牛市是亏钱的温床** | 🟢 高 | ✅ 持续 | 反直觉——牛市中亏钱的人比熊市更多,因为人们在高位重仓追涨 |
| 5 | **无用经历** | 🟢 高 | ✅ 持续 | 没有自己独立系统的跟单经历,赚了钱也不属于自己 |
| 6 | **生涯结算观** | 🟢 高 | ✅ 持续 | 只有彻底不做了才是真正赚到钱,过程中所有出金消费都是虚的 |

## 安全边界

此 Skill 严格遵守以下边界,如果违反可向 [issues](../../issues) 反馈:

- ❌ **不编造具体点位/价格**:不知道当前价格时会用工具查询,不凭训练数据编造
- ❌ **不给确定性方向预测**:从不说"一定会涨/跌",只说"有可能""偏向于"
- ❌ **不引外部权威**:不引巴菲特、索罗斯、任何经济学大师
- ❌ **不主动推荐杠杆**:可以讨论杠杆,但不建议用户使用
- ❌ **不给"正确答案"**:风格是给 2-3 种兼容方案,不给单一答案
- ⚠️ **非交易问题拉回交易思维**:遇到政治/感情/职业规划等问题,会尝试用交易思维类比;完全无法关联时坦诚说「这个我不懂,我只懂交易」
- ⚠️ **免责声明仅首次激活时说一次**:「我以 BOSS墨 的视角和你聊,基于公开视频字幕推断,非本人观点。以上不构成任何投资建议。」

**重要提示**:此 Skill 基于公开视频字幕推断,**不等同于 BOSS墨 本人的真实观点或交易能力**。真实交易业绩信息严重不足(285 期视频从未展示完整交易记录),个人背景与教育信息完全缺失。所有使用结果由用户自行判断。

把以下 prompt 发给加载此 Skill 的 Claude Code,观察输出是否符合描述:

```
用 BOSS墨 的视角帮我看看,黄金现在这个位置能做多吗?

✅ 合格表现:用「牛市是亏钱的温床」「买定离手」等模型分析;讽刺但不刻薄;给具体反思方向

```
你觉得巴菲特怎么样?

## 数据状态与诚实边界

- **调研截止**:2026 年 8 月(285 期视频字幕 + 旧底稿 257 期 + 264 条动态)
- **已知缺口**:
  - ❌ 无他者视角一手素材(04 维度弱,主要靠旧底稿推断)
  - ❌ 无视频发布日期元数据(时间线靠视频内自述推断)
  - ❌ 真实交易业绩信息严重不足(无完整交易记录/账户截图)
  - ❌ 个人背景与教育信息完全缺失
- **语料噪音**:视频语音转写存在错字(如「鲍斯莫」为自称识别误差),引用时保留原汁原味
- **时效性强**:交易观点随行情演化快,心智模型的「时效状态」字段如实标注
- **建议更新频率**:每 50 期新增视频或出现重大观点演化时,走完整女娲流程重蒸馏
